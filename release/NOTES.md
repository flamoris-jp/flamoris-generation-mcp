# flamoris-generation-mcp v1.0.5

Embeds Controller 1.0.2 with internal-service-only bounded discovery of completed external generations. Studio can automatically import its linked Hub client's results using verified provenance and its own account authorization. The external MCP catalog remains at 25 tools; no discovery tool is exposed externally.

Preserves saved recipes, jobs/assets, unknown/no-replay reservations, configured YuE2 output placement and provider settings. Compatible updates retain runtime.env and existing data; no model download, GPU activation or output relocation is required.

Individual Hub credentials, matching signed-provenance configuration and Studio account bindings remain operator settings. Publishing/updating the image alone does not assign existing anonymous results to a user.
